# Retail Business Performance & Profitability Analysis

## Project Overview
This project analyzes the Sample Superstore dataset using Python to understand sales performance, profitability, customer behavior, and regional trends through Exploratory Data Analysis (EDA).

## Objective
The objective of this project is to analyze retail sales data and identify business insights that can help improve profitability and support better business decision-making.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- GitHub

## Dataset
- Sample Superstore Dataset (CSV)

## Project Workflow
1. Loaded the dataset into Google Colab.
2. Explored the dataset using `head()`, `info()`, and `describe()`.
3. Checked for missing values and duplicate records.
4. Performed Exploratory Data Analysis (EDA).
5. Created visualizations for:
   - Sales by Category
   - Profit by Category
   - Sales by Region
   - Profit by Region
   - Monthly Sales Trend
   - Sales by Customer Segment
   - Top 10 States by Sales
   - Discount vs Profit Analysis
6. Derived business insights and conclusions.

## Key Insights
- Technology generated the highest profit.
- West region recorded the highest sales and profit.
- Consumer customers contributed the highest sales.
- California was the top-performing state by sales.
- Higher discounts were often associated with lower profitability.
